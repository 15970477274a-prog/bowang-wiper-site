# Bowang Wiper Site

Ningbo Zhenhai Bowang Autoparts Co., Ltd. - Wiper Blade Manufacturer B2B Independent Station

## Tech Stack
- **Framework**: Next.js 16 (React 19)
- **Hosting**: Vercel
- **Domain**: [lelionautopart.com](https://www.lelionautopart.com)
- **Image Storage**: Cloudflare R2

## Features
- SEO & AEO optimized (FAQPage, BreadcrumbList, Organization, WebSite, Product, Article schemas)
- Multilingual support (EN/ES/RU/FR/DE)
- Blog module with 5 SEO articles
- Product category routing (universal, specific-fit, multifunction)
- Enhanced inquiry form (WhatsApp, quantity fields)
- Mobile responsive with hamburger menu
- Image lazy loading
